## 🎯 PHILOSOPHIE DE DESIGN

Mendly doit être **une démonstration de design**. Chaque section = un nouveau monde visuel.
Le scroll est un voyage : cosmique → froid → lumineux → dynamique → humain → tech → éditorial → factuel → premium → sécurisé → épique.

Chaque transition entre sections doit être **un changement d'ambiance** (couleurs dominantes, effets, mouvement).

## 📋 WORKFLOW D'UTILISATION

Quand Claude Code doit implémenter une section :

1. **Lire ce fichier** pour voir quels composants sont pré-approuvés pour cette section
2. **Installer le composant via `/ui [URL du composant]`** ou `npx shadcn@latest add [URL]`
3. **Customiser** : remplacer toutes les couleurs par les CSS variables Mendly (`--accent-primary`, `--accent-hot`, etc.)
4. **Intégrer** les traductions via `useTranslations`
5. **Respecter** CLAUDE.md (pas de localStorage, pas de `<img>`, mobile-first, etc.)
6. **Tester** sur desktop + mobile avant validation

Si un composant pré-approuvé ne fonctionne pas pour une raison précise (bug, incompatibilité), Claude peut chercher une alternative via `/ui`, mais doit **toujours** privilégier cette liste.

---

## 🎨 RÈGLES DE CUSTOMISATION

Tous les composants 21st.dev DOIVENT être customisés pour matcher Mendly :

- Couleurs hardcodées (genre `bg-blue-500`, `text-purple-600`) → REMPLACER par `bg-[var(--accent-primary)]`, `text-[var(--accent-glow)]`
- Arrondis par défaut → `rounded-3xl` ou `rounded-[32px]` minimum sur les cards
- Animations standard → durées plus longues (700-900ms) avec `cubic-bezier(0.16, 1, 0.3, 1)`
- Textes → toujours via `useTranslations`, jamais hardcodés
- Polices → Geist par défaut, Fraunces italic pour les moments éditoriaux
